## 한 주를 지내며 생각한 것

- Grid와 Flexbox의 차이점을 명확히 이해하게 되었다. 1차원 배치는 Flexbox, 2차원 배치는 Grid가 적합하다.
- `display: contents`와 `grid-template-areas` 같은 기능들은 처음 접했는데 레이아웃 구성이 훨씬 유연해진다.
- 반응형 웹을 구현할 때 모바일과 데스크톱의 레이아웃 방식을 완전히 다르게 가져가는 것도 좋은 방법임을 알게 되었다.
- 테이블의 `sticky` 헤더는 데이터가 많은 표에서 사용자 경험을 크게 개선할 수 있어서 앞으로 적극 활용해야겠다.
- CSS 레이아웃 기법들이 점점 강력해지고 있어서, 예전처럼 float이나 position만으로 레이아웃을 짜던 시절보다 훨씬 편해졌다.
