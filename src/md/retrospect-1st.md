# 첫 번째 회고

> 1월 5일 ~ 9일 까지의 회고와 느낀점 입니다!

## 느낀점

| 날짜     | 회고 느낀점                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 26.01.05 | 깃 저장소 초기화 및 브랜치, Github Repository 사용방법을 배웠다. 터미널을 통해 폴더/파일 생성, 삭제, 정보 확인하는 방법과 `git remote`로 로컬과 Repository 연결, `git clone`으로 복사하는 방법을 익혔다. 기존에는 `checkout`으로 브랜치를 이동했는데, `checkout`에 많은 역할이 있음을 알게 되어 앞으로는 `switch`를 사용해서 브랜치 이동만 하는 습관을 가져야겠다. Finder 대신 터미널로 파일/폴더를 만드는 습관도 들여야 한다. |
| 26.01.06 | npm의 글로벌 설치와 패키지 매니저 개념을 배웠다. `degit`을 통한 복제, `live-server`로 저장과 동시에 반영, `prettier`로 포맷 설정하는 방법을 익혔다. `.gitignore`을 통해 Github에 올라가지 않을 파일을 제한할 수 있음을 알게 되었다. 이전에는 npm을 패키지로만 사용해서 버전관리가 안 되었는데, 패키지 매니저를 통한 버전관리 방법을 배웠다.                                                                                    |
| 26.01.07 | `vite`를 통한 live-server 사용법과 Tailwind를 사용한 간단한 CSS를 배웠다. `prettier`를 통해 적절한 포맷팅을 적용하는 방법을 익혔다.                                                                                                                                                                                                                                                                                            |
| 26.01.08 | `git clone`을 통한 repository 복사, `emmet`을 이용한 간단한 구조 만들기, `snippet`을 통한 단축어 만들기를 배웠다. 이전까지는 수작업으로 타이핑했는데 emmet을 통해 빠르게 구조를 구성할 수 있게 되었고, snippet으로 자주 쓰는 코드들을 저장해서 효율적으로 작업할 수 있게 되었다.                                                                                                                                               |
| 26.01.09 | `rel` 속성으로 새 창 열기, `download` 속성으로 PDF 다운로드, `ol`/`ul`/`li`를 통한 리스트 활용법을 배웠다. `dl`/`dt`/`dd`를 통한 정의 목록 구조와 `div`, `main`, `section`, `footer` 등 시맨틱 태그를 익혔다. Github Pages 배포 방법도 배웠다. 이전에는 `div`만으로 섹션을 분류했는데, 이제는 `main`, `footer` 등 의미에 맞는 태그를 사용해야겠다.                                                                             |
